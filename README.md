# 🍺 Štamgast Simulátor 3D

Hospodská 3D hra v prohlížeči: drž balanc na stoličce, chytej drinky, přežij do zavíračky ve 4:00.
Herna (ruleta, automat, blackjack, poker, kostky), online žebříček a hospodský chat.

**Hrát:** https://sokneb.github.io/stamgast-simulator/

Jeden soubor `index.html` + hudba ve složce `music/`. Žebříček a chat běží na Supabase (`supabase.sql`).
